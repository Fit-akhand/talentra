## What DEC-25 does not settle

- The consuming application does not exist in this repository; `scripts/identifier_crypto.py` is the reference it must follow. Until it exists, nothing real can be stored safely except through that module.
- Seed data uses a fixed, public development key (`dev_root_key()`). It protects nothing.
- Canonical forms are implemented for GSTIN, PAN, CIN, EIN, VAT and company number from published formats; a domain expert has not reviewed them. VAT and company numbers are only length-checked.
- The staged migration for a database that already holds plaintext identifiers is described in the design (section 6), not automated.
